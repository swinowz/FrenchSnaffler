# Fichiers de test historiques

Ce répertoire provient du corpus de test de Snaffler. Ses noms de fichiers
servent à exercer les règles de détection ; la plupart des fichiers sont vides.
Les anciennes clés SSH et leurs fichiers publics ont été remplacés par des
marqueurs inertes : ce corpus ne valide donc pas la lecture de clés privées.
Les certificats publics hérités sont conservés. Le profil RDP de démonstration
a été nettoyé : mot de passe chiffré retiré et adresse remplacée par un exemple.

Ne jamais ajouter ici de véritables identifiants, clés privées ou résultats
d’audit. Pour tester la détection de contenu, utiliser des données synthétiques
dans un répertoire local distinct, hors du dépôt.
